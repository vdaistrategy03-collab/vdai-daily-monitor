## 신규 발표 확인 사항

1. **Apple TV: `tvOS 27.0 RC` 개발자 배포**
   - 상태: **공식 확인**
   - 발표 시점: 2026-09-10 (KST 기준)
   - 분류: TV 플랫폼/UX
   - 내용
     - Apple Developer Releases에 `tvOS 27.0 RC` 빌드 `24J360` 등록
     - 개발자 대상 사전 배포로 최종 앱·미디어 재생·기기 호환성 점검 단계
     - 일반 배포 일자와 상세 기능·호환 기기 목록은 해당 등록 페이지 미공개
   - 관련성: 상 (Apple TV OS·앱 경험 직접 변화)
   - 중요도: 중 (RC 단계, 일반 배포 조건 미정)
   - 인사이트
     - 의미: Apple TV의 차기 플랫폼 전환이 확정 단계에 들어가 프리미엄 스트리밍 박스 UX 경쟁의 기준점이 될 가능성 있음
     - 참고할 점: 공개 릴리스 노트와 Apple TV 앱·음악·팟캐스트·접근성 기능의 최종 변경점 확인 필요
     - 제안: Tizen의 이어보기·개인화·미디어 앱 호환성에 영향을 줄 기능과 지원 제외 기기를 일반 배포 직후 대조 필요
   - 출처
     - [Apple Developer Releases](https://developer.apple.com/news/releases/?id=02262026)
     - [Apple TV 소프트웨어 업데이트 안내](https://support.apple.com/en-ie/106336)

2. **LG webOS TV: 로컬 네트워크·음성 데이터 처리 의혹에 대한 조사 및 LG 반박**
   - 상태: **주요 매체 확인**
   - 발표 시점: 2026-09-08~2026-09-10
   - 분류: TV 플랫폼/UX
   - 내용
     - Gamers Nexus·협력 연구진의 패킷 캡처 기반 조사에서 `OLED65G3PUA`와 G5 OLED의 로컬 네트워크 스캔, ACR·음성 처리 관련 주장 제기
     - Ars Technica가 조사에서 사용한 모델·Wireshark 시험과 LG의 반박을 보도했으나, 원조사의 전체 주장과 LG 반박 모두 독립 재현 전 단계
     - LG는 음성 데이터가 리모컨 음성 버튼 길게 누름 또는 사용자가 켠 Far-Field 음성 인식의 웨이크워드 인식 때만 처리되며, ACR 광고 활용은 옵트인이라고 설명
   - 관련성: 상 (TV ACR·음성·스마트홈 데이터 신뢰 직결)
   - 중요도: 상 (프라이버시·보안·광고 플랫폼 평판 위험)
   - 전략적 의도
     - [데이터 수익화 방어]: ACR 기반 개인화·광고 기능의 옵트인 구조를 강조해 기능 지속성과 신뢰 훼손을 함께 방어하려는 대응 가능성 있음
     - [AI UX 신뢰 회복]: 음성 처리의 기기 내 웨이크워드 판별을 전면에 내세워 거실 AI 기능의 상시 수집 인식을 낮추려는 시나리오로 보임
   - 인사이트
     - 의미: TV AI·광고 기능의 동의 설계와 대기 상태 데이터 처리가 제품 경쟁력의 신뢰 조건으로 부상할 가능성 있음
     - 참고할 점: 시험 펌웨어·동의 설정·네트워크 차단 조건별 재현, LG의 원격 음성 인식·ACR 구현 증빙 확인 필요
     - 제안: Samsung TV의 ACR·음성·LAN 탐색 권한을 기능별로 분리해 기본값, 전송 시점, 철회 경로, 오프라인 동작을 외부 감사 관점에서 점검 필요
   - 출처
