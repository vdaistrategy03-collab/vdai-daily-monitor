   - 발표 시점: 2026-09-22
   - 분류: TV 플랫폼/UX
   - 내용
     - 다년 제휴 확장으로 Best Buy 생산 Insignia TV의 Fire TV 독점 소프트웨어 경험 유지
     - 2027년 2월부터 Best Buy Ads의 Amazon Ads 프로그래매틱·AI 도구 활용, 신규·기존 Insignia TV Fire TV 광고 인벤토리 제공
     - 24~85형 Insignia 제품에 최신 Fire TV UI와 다수 모델 Alexa+ 탑재, Best Buy의 오프라인·Amazon 내 독점 판매 구조 유지
   - 관련성: 상 (TV OS·광고·유통 결합 직접 영향)
   - 중요도: 상 (대형 유통 TV군의 독점 플랫폼·광고 측정 확대)
   - 전략적 의도
     - [유통 잠금 시나리오]: Best Buy 자체 브랜드의 OS 독점을 연장해 저가·중가 TV 설치 기반을 Fire TV 생태계에 고정하려는 확장 가능성
     - [광고 수익화 시나리오]: 기보유 TV까지 광고 인벤토리·성과 측정에 묶어 하드웨어 판매 외 CTV 수익을 키우려는 경로로 해석 가능
   - 인사이트
     - 의미: TV OS 선택과 리테일 채널, CTV 광고 측정을 하나의 제휴 단위로 묶는 경쟁 모델 확대 가능성 있음
     - 참고할 점: Insignia 실판매 모델의 Alexa+ 적용률·광고 노출 위치·옵트아웃 및 데이터 결합 범위 추적 필요
     - 제안: Samsung TV Plus·Tizen Ads의 리테일 파트너별 재고·측정·동의 UX를 비교해 공동판매 패키지 점검 필요

2. **Roku: RSG 2.0 TypeScript SDK 베타 및 Roku Cloud Emulator 공개**
   - 상태: **공식 확인**
   - 발표 시점: 2026-09-23
   - 분류: TV 플랫폼/UX
   - 내용
     - Roku Developer Summit에서 SceneGraph 기반 RSG 2.0 SDK의 TypeScript 지원과 10월 29일 공개 베타·MIT 오픈소스 계획 발표
     - GitLab 기반 SDK·문서 기여 수용 방침으로 개발 도구와 문서의 공개 협업 경로 제시
     - 최신 Roku OS 가상 스트리밍 플레이어·TV를 웹 UI·REST API로 테스트하는 Roku Cloud Emulator 발표, 실제 기기 없이 앱 실행·리모컨·사이드로드·디버그 검증 지원
   - 관련성: 상 (TV 앱 개발·검증 생태계 직접 영향)
   - 중요도: 상 (언어 전환·클라우드 테스트 경로 신설)
   - 전략적 의도
     - [개발자 확대 시나리오]: TypeScript와 오픈소스 기여를 도입해 웹 개발자 유입 및 앱 공급 속도 개선을 노린 전환 가능성
     - [품질 자동화 시나리오]: 가상 Roku OS·API 테스트로 기기 조달 없이 CI/CD를 지원해 앱 출시·유지 비용을 낮추려는 플랫폼 방어 가능성
   - 인사이트
     - 의미: TV 플랫폼 경쟁이 소비자 UI뿐 아니라 개발 언어·클라우드 QA 생산성 경쟁으로 이동할 가능성 있음
     - 참고할 점: RSG 2.0의 기존 BrightScript 호환성, 베타 참여 조건, Cloud Emulator의 실제 OS·DRM·성능 재현 범위 확인 필요
     - 제안: Tizen TV 앱 도구의 TypeScript 친화성·가상 디바이스·자동화 API 제공 수준을 Roku 공개 베타와 비교 점검 필요
   - 출처
     - [Roku Developer Blog: RSG 2.0 SDK 공개 베타](https://dev-blog.us-east-1.msc.roku.com/developer)
     - [Roku Developer Blog: Roku Cloud Emulator](https://dev-blog.us-east-1.msc.roku.com/developer)
